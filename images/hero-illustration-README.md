# Hero illustration

Drop a file named exactly `hero-illustration.png` into `images/` (i.e. `images/hero-illustration.png`) and it will
automatically appear below the hero buttons at the top of the page, replacing the current blank placeholder.

Tips:
- Displayed at up to 480px wide, so anything from roughly 480&ndash;960px wide works well.
- A transparent background blends best with the hero's light gradient.
