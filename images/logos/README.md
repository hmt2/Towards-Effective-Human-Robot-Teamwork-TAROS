# Partner logos

Drop logo files here with these exact filenames so `index.html` picks them up automatically:

- `university-of-manchester.png` (or `.svg`) &mdash; University of Manchester logo
- `taros.png` (or `.svg`) &mdash; TAROS conference logo

Until a file is present, that logo slot stays blank (no broken-image icon).

Tips:
- SVG or a PNG with a transparent background works best against the white strip.
- Logos are shown at a fixed height (40px) with width scaling automatically, so any reasonable source size works.
